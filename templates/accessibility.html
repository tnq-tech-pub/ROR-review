TNQTech is committed to making the Affiliation Review application usable by as many people as possible. This statement describes our accessibility goals for this independent community tool supporting the ROR ecosystem.

1. Commitment

We aim to conform to the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA where practical for a lightweight internal/community web application. Accessibility improvements are treated as ongoing work alongside feature development.

2. Measures we take

  • Semantic HTML structure for primary views and documentation pages
  • Text alternatives for key images (for example, ROR and TNQTech logos)
  • Visible focus styles on interactive controls
  • Keyboard access for primary actions (navigation, file browse, form controls, modal close)
  • Color is not the only means of conveying match status (labels and badges include text)
  • Responsive layout for common desktop and narrower viewports

3. Known limitations

Some areas may present barriers today:

  • Large results tables can be difficult to navigate with screen readers; we plan clearer table captions and improved header associations.
  • Drag-and-drop upload is supplemented by a standard file input; ensure you can use “Upload file” if drag-and-drop is unavailable.
  • Bulk verification prompts and some alerts currently use browser dialogs, which vary by assistive technology.
  • Color contrast for some secondary footer text may need further refinement on certain displays.

4. Compatibility

The Tool is designed for current evergreen browsers (Chrome, Firefox, Edge, Safari). JavaScript is required for processing, filtering, and review workflows.

5. Assistive technologies

We test with common combinations of browsers and platform accessibility features during development. If you encounter a blocker with a specific assistive technology, please report it via GitHub Issues so we can prioritize a fix.

6. Feedback

We welcome accessibility feedback on this Tool. Please open an issue on GitHub Issues and include:

  • The page or workflow where the issue occurred
  • Your browser, operating system, and assistive technology (if any)
  • A short description of the barrier and the expected behavior
